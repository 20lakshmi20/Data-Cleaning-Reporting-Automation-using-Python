# Data Cleaning & Reporting Automation using Python

## Overview

This project automates the process of cleaning and preparing employee data using Python. It handles common data quality issues such as missing values, duplicate records, and inconsistent formatting, then generates summary statistics and visual reports.

## Features

* Load Excel dataset using Pandas
* Detect missing values
* Fill missing Salary values with the mean
* Fill missing Experience values with the median
* Remove duplicate records
* Standardize department names
* Generate summary statistics
* Create department-wise and salary distribution charts
* Export the cleaned dataset to a new Excel file

## Technologies Used

* Python
* Pandas
* Matplotlib
* OpenPyXL

## Dataset

The project uses a messy employee dataset containing:

* Employee ID
* Employee Name
* Department
* Salary
* Experience

The dataset intentionally includes:

* Missing values
* Duplicate records
* Inconsistent department names

## Project Workflow

1. Import the employee dataset.
2. Identify missing values and duplicate records.
3. Clean the dataset by filling missing values and removing duplicates.
4. Standardize department names for consistency.
5. Generate summary statistics.
6. Visualize department distribution and salary distribution.
7. Save the cleaned dataset as a new Excel file.

## Project Output

* Cleaned Employee Dataset (`Cleaned_Employee_Dataset.xlsx`)
* Department Distribution Chart
* Salary Distribution Chart
* Summary Statistics displayed in the terminal
